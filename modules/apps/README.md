# `apps`

User-facing applications, organized by what I use them for rather than what they
technically are.

## Layout

- `ai/`: general-purpose AI assistant tooling
- `browsers/`: web browsers
- `creative/`: content creation and editing tools
- `development/`: dev tools, CLIs, and IDE integrations
- `devices/`: bridges to companion devices (phone, earbuds)
- `gaming/`: gaming stack and tools
- `media/`: music, video, and streaming apps
- `productivity/`: personal organization
- `social/`: chat and video call apps
